# Tracker33 - Система мониторинга рабочего времени

## 🎯 Основные возможности

### 📊 Веб-интерфейс
- **Dashboard** - обзор дневной активности
- **Статистика** - подробная аналитика по приложениям  
- **Логи** - детальная история активности
- **Цели** - установка целей рабочего времени

### 💻 Desktop клиент
- Автоматическое отслеживание активных приложений
- Подсчет нажатий клавиш и кликов мыши
- Синхронизация с веб-сервисом
- Системный трей и уведомления

## 🚀 Быстрый старт

### Веб-сервер

1. **Установка зависимостей:**
```bash
pip install -r requirements.txt
```

2. **Настройка базы данных:**
```bash
python manage.py migrate
python manage.py createsuperuser
```

3. **Запуск сервера:**
```bash
python manage.py runserver 0.0.0.0:8000
```

### Desktop клиент

1. **Скачать готовый EXE:** [TimeTracker.exe](http://localhost:8000/accounts/download-tracker/)
2. **Запустить как администратор** (для корректного отслеживания активности)
3. **Настроить подключение к серверу** в настройках приложения

## 🛠 Технологии

- **Backend:** Django 5.1, Django REST Framework
- **Frontend:** Bootstrap 5, Chart.js, D3.js
- **Database:** SQLite (по умолчанию)
- **Desktop:** Python, Tkinter, PyInstaller
