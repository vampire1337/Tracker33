## 🌐 Сетевая настройка

### Почему 127.0.0.1:8001?

1. **127.0.0.1** - локальный интерфейс (loopback)
   - Безопасность: доступ только с того же компьютера
   - Изоляция: не виден из сети
   - Отладка: стабильный адрес для разработки

2. **Порт 8001**
   - Альтернатива стандартному Django порту 8000
   - Избежание конфликтов с другими приложениями
   - Легко запомнить и настроить

### Настройки для продакшена

Для доступа по сети измените в `start_server.bat/sh`:
```bash
python manage.py runserver 0.0.0.0:8001
```

При возникновении проблем:
1. Проверьте, что сервер запущен на 127.0.0.1:8001
2. Убедитесь, что порт 8001 не заблокирован
