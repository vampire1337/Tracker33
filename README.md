## 📋 Описание

**Tracker33** - это профессиональная система мониторинга активности пользователей ПК, разработанная для отслеживания рабочего времени, анализа продуктивности и мониторинга использования приложений.

### ✨ Ключевые возможности:

- 🔍 **Автоматическое отслеживание** всех запущенных приложений
- ⌨️ **Мониторинг клавиатурной активности** с подсчетом нажатий
- 🖱️ **Отслеживание активности мыши** (клики, движения)
- ⏱️ **Точный учет времени** работы в каждом приложении
- 🌐 **Веб-интерфейс** для просмотра статистики и отчетов
- 📊 **Детализированная аналитика** производительности
- 🔄 **Синхронизация в реальном времени** с сервером
- 🛡️ **Защищенная передача данных** с авторизацией
- 💤 **Определение простоя** пользователя
- 🎛️ **Гибкие настройки** отслеживания

## 🔧 Конфигурация

Основные настройки находятся в файле `desktop_app/config.ini`:

```ini
[Settings]
update_interval = 5              # Интервал обновления (сек)
send_interval_seconds = 10       # Интервал отправки данных (сек)
idle_threshold_seconds = 300     # Порог простоя (сек)
demo_mode = False               # Демо-режим (без отправки)

[Server]
base_url = http://147.45.153.16:8000    # URL сервера
```

## 🔧 Устранение неполадок

### Приложение не запускается:
1. Убедитесь что запускаете **от имени администратора**
2. Проверьте антивирус (добавьте в исключения)
3. Установите Visual C++ Redistributable

### Не отслеживается клавиатура:
1. Запустите приложение **с правами администратора**
2. Проверьте настройки антивируса
3. Убедитесь что библиотека pynput установлена

### Данные не отправляются на сервер:
1. Проверьте подключение к интернету
2. Обновите токен авторизации
3. Проверьте логи в папке `logs/`
