=============================================
    TRACKER33 - СИСТЕМА УЧЕТА ВРЕМЕНИ
=============================================

🎯 ЧТО ЭТО?
Полная система для автоматического отслеживания времени работы на компьютере
+ Web-интерфейс для просмотра статистики
+ Desktop-клиент для отслеживания активности

📋 ТРЕБОВАНИЯ:
✅ Python 3.8+ (обязательно с галочкой "Add to PATH")
✅ Windows 10/11
✅ Интернет не требуется (работает локально)

🚀 БЫСТРЫЙ ЗАПУСК:
1️⃣ Запустите: ЗАПУСК_СИСТЕМЫ.bat (это запустит веб-сервер)
2️⃣ Откройте браузер: http://127.0.0.1:8001
3️⃣ Создайте пользователя через админку
4️⃣ Запустите: ЗАПУСК_КЛИЕНТА.bat (это запустит отслеживание)

⚠️ ВАЖНО:
- СНАЧАЛА сервер, ПОТОМ клиент!
- Графики временно отключены (система в упрощенном режиме)
- База данных создается автоматически

📁 СТРУКТУРА:
- ЗАПУСК_СИСТЕМЫ.bat     → Запуск веб-сервера
- ЗАПУСК_КЛИЕНТА.bat     → Запуск клиента отслеживания  
- README_ДЛЯ_ЗАКАЗЧИКА.md → Подробная документация
- static/downloads/      → Готовый EXE файл клиента

🔑 ПЕРВЫЙ ВХОД:
1. Запустите сервер (ЗАПУСК_СИСТЕМЫ.bat)
2. Откройте http://127.0.0.1:8001/admin/
3. Создайте суперпользователя: python manage.py createsuperuser
4. Создайте обычных пользователей через админку
5. Эти же данные используйте в клиенте

📞 ПОДДЕРЖКА:
- Проверьте логи в папке %APPDATA%/TimeTracker/logs/
- Убедитесь что Python установлен: python --version
- Проверьте что сервер запущен: netstat -ano | findstr :8001

✅ СИСТЕМА ГОТОВА К РАБОТЕ!
