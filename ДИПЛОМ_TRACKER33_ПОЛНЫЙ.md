### 2.3 Алгоритм классификации

Разработан алгоритм автоматической классификации активности:

```python
def classify_activity(app_name, window_title):
    # Правила классификации по имени приложения
    productive_apps = ['vscode', 'pycharm', 'excel', 'word']
    distracting_apps = ['youtube', 'facebook', 'instagram']
    
    if any(app in app_name.lower() for app in productive_apps):
        return 'productive'
    elif any(app in app_name.lower() for app in distracting_apps):
        return 'distracting'
    else:
        return 'neutral'
```

### 3.2 Desktop-приложение (PyQt6)

Ключевые модули:
- **ActivityTracker** - мониторинг активности
- **APIClient** - взаимодействие с сервером
- **DataProcessor** - обработка и классификация данных
- **SystemTray** - интеграция с системным треем

```python
class ActivityTracker:
    def track_activity(self):
        while self.running:
            active_window = self.get_active_window()
            app_data = {
                'name': active_window.name,
                'process_name': active_window.process,
                'timestamp': datetime.now()
            }
            self.send_to_server(app_data)
            time.sleep(5)
```
