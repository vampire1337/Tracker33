Этот раздел предназначен только для опытных администраторов, которые понимают структуру базы данных. Здесь отображаются сырые данные системы.

  • НЕ ИЗМЕНЯЙТЕ данные напрямую в базе!

Для чего это нужно?

База данных хранит всю информацию системы в виде таблиц. Здесь можно посмотреть сырые данные для диагностики проблем, которые не видны в обычном интерфейсе. Например, проверить, правильно ли записываются данные от клиентов или есть ли дублирующиеся записи.
