## 🔧 Автоматизированное тестирование

### Настройка тестовой среды

1. **Установка зависимостей**
```bash
pip install pytest pytest-django requests
```

2. **Запуск Django тестов**
```bash
python manage.py test
```

3. **Запуск с покрытием**
```bash
pip install coverage
coverage run --source='.' manage.py test
coverage report
coverage html
```

### API тесты с Python

```python
import requests
import json

# Базовая настройка
BASE_URL = "http://localhost:8001"
USERNAME = "testuser"
PASSWORD = "testpass"

# Получение токена
def get_auth_token():
    response = requests.post(f"{BASE_URL}/api-token-auth/", {
        "username": USERNAME,
        "password": PASSWORD
    })
    return response.json()["token"]

# Тест API активности
def test_activity_api():
    token = get_auth_token()
    headers = {"Authorization": f"Token {token}"}
    
    # GET запрос
    response = requests.get(f"{BASE_URL}/api/activity/", headers=headers)
    assert response.status_code == 200
    
    # POST запрос
    data = {
        "activities": [{
            "application_name": "Test App",
            "process_name": "test.exe",
            "start_time": "2024-01-15T10:00:00Z",
            "end_time": "2024-01-15T11:00:00Z",
            "keyboard_presses": 100
        }]
    }
    response = requests.post(f"{BASE_URL}/api/activity/", 
                           headers=headers, json=data)
    assert response.status_code == 201
```

## 🚀 Тестирование развертывания

### Локальное развертывание

1. **Подготовка окружения**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
pip install -r requirements.txt
```

2. **Миграции и статика**
```bash
python manage.py migrate
python manage.py collectstatic
python manage.py createsuperuser
```

3. **Запуск и тестирование**
```bash
python manage.py runserver 8001
```

### Docker тестирование

1. **Использование готового скрипта**
```bash
# Linux/Mac
./scripts/test-docker.sh

# Windows
scripts\test-docker.bat
```

2. **Ручное тестирование**
```bash
# Сборка
docker build -t tracker33 .

# Запуск с docker-compose
docker-compose up -d

# Проверка
curl http://localhost:8001/api/health/
```

## 🐛 Устранение неполадок

### Частые проблемы

1. **Сервер не запускается**
   - Проверить порт 8001
   - Убедиться в применении миграций
   - Проверить переменные окружения

2. **API возвращает 500 ошибку**
   - Проверить логи Django
   - Убедиться в правильности токена
   - Проверить подключение к БД

3. **Клиент не подключается**
   - Проверить config.ini
   - Убедиться в доступности сервера
   - Проверить учетные данные

4. **Docker контейнеры не запускаются**
   - Проверить логи: `docker logs container_name`
   - Убедиться в наличии свободных портов
   - Проверить переменные окружения
