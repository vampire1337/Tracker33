# 🎯 Tracker33 - Система мониторинга активности ПК

## 📋 Описание проекта

**Tracker33** - готовая система мониторинга рабочего времени и активности пользователей ПК, состоящая из клиентского приложения для Windows и веб-интерфейса для анализа данных.

## 🎯 Реализованные возможности

### 🖥️ Клиентское приложение
- **Автоматическое отслеживание** всех запущенных приложений
- **Мониторинг клавиатурной активности** с подсчетом нажатий
- **Отслеживание активности мыши** (клики, движения)
- **Точный учет времени** работы в каждом приложении
- **Определение периодов простоя** пользователя
- **Защищенная передача данных** на сервер
- **Автоматический запуск** при старте системы
- **Работа в фоновом режиме** (< 50 МБ RAM)

### 🌐 Веб-интерфейс
- **Дашборд** с общей статистикой активности
- **Детализированные отчеты** по приложениям
- **Временные графики** с фильтрацией по датам
- **Анализ продуктивности** с классификацией приложений
- **Экспорт данных** (CSV, PDF)
- **Многопользовательская система** с разграничением доступа
- **Адаптивный дизайн** для всех устройств

## 🔧 Технические характеристики

### Системные требования
- **ОС**: Windows 10 (1903+) или Windows 11
- **RAM**: минимум 512 МБ
- **Диск**: 50 МБ для установки
- **Сеть**: подключение к интернету
- **Права**: администратор для полного функционала

### Технологии
- **Клиент**: Python 3.8+, PyQt5, pynput, psutil
- **Сервер**: Django 4.0+, PostgreSQL
- **Безопасность**: JWT токены, HTTPS, шифрование

## 📊 Функционал

### Мониторинг
- Отслеживание активных окон и времени работы
- Подсчет клавиатурной и мышиной активности
- Определение периодов неактивности
- Классификация приложений на продуктивные/непродуктивные

### Отчетность
- Ежедневные, недельные, месячные отчеты
- Графики использования времени
- Топ используемых приложений
- Анализ эффективности работы
