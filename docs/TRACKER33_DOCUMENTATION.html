1. Введение и архитектура

1.1 Описание проекта

Tracker33 представляет собой комплексную систему мониторинга рабочего времени, состоящую из веб-приложения на Django и desktop клиента на PyQt6. Система автоматически отслеживает активность пользователя, анализирует использование приложений и предоставляет детальную статистику продуктивности.

Ключевые особенности:
  • Автоматическое отслеживание: Мониторинг активных приложений без участия пользователя
  • QR-аутентификация: Современная система подключения через QR-коды
  • Реальное время: Синхронизация данных каждые 60 секунд
  • Кроссплатформенность: Поддержка Windows, Linux, macOS
  • Веб-интерфейс: Современный dashboard с аналитикой
  • Системный трей: Незаметная работа в фоне

def get_active_window(self) -> Optional[Dict[str, str]]:
    try:
        if platform.system() == "Windows":

6. Система аутентификации

6.1 QR-код аутентификация

Современный подход: Система QR-аутентификации обеспечивает безопасное и удобное подключение клиентов без необходимости ввода учетных данных.

Процесс QR-аутентификации:

  1. Генерация QR-кода: Веб-сервер создает временный токен (10 минут)
  2. Отображение QR-кода: Пользователь видит QR-код на веб-странице
  3. Сканирование: Desktop клиент сканирует QR-код через камеру
  4. Аутентификация: Клиент отправляет токен на сервер
  5. Подключение: Сервер выдает API токен для дальнейшей работы

Безопасность QR-токенов:

  • Короткое время жизни: Токены действуют только 10 минут
  • Одноразовое использование: Каждый токен можно использовать только один раз
  • HTTPS обязательно: Все запросы защищены SSL/TLS
  • Проверка Origin: Защита от CSRF атак

6.2 Генерация QR-кода

@api_view(['POST'])
@permission_classes([AllowAny])
def generate_qr_token(request):
    # Создаем анонимный QR токен
    qr_token = QRToken.generate_token(expires_minutes=10)
    
    # Данные для QR кода
    qr_data = {
        'token': qr_token.token,
        'server_url': request.build_absolute_uri('/'),
        'api_url': request.build_absolute_uri('/api/'),
        'expires_at': qr_token.expires_at.isoformat()
    }
    
    # Создаем QR код
    qr = qrcode.QRCode(version=1, error_correction=qrcode.constants.ERROR_CORRECT_L)
    qr.add_data(json.dumps(qr_data))
    qr.make(fit=True)
    
    return Response({
        'success': True,
        'token': qr_token.token,
        'qr_image': f"data:image/png;base64,{qr_image_base64}",
        'expires_at': qr_token.expires_at
    })

8. Безопасность системы

8.1 Анализ угроз QR-аутентификации

Основные угрозы:
  • Quishing (QR phishing): 20% всех онлайн-мошенничеств в 2024
  • Подмена QR-кодов: Замена легитимных кодов вредоносными
  • Установка малварэ: QR-коды могут содержать ссылки на вредоносное ПО
  • Кража данных: Перехват личной информации

8.2 Меры защиты

Реализованные защитные меры:
  • Встроенный сканер: Использование собственного QR-сканера вместо сторонних приложений
  • Проверка URL: Валидация адресов перед подключением
  • Короткие токены: Время жизни токенов ограничено 10 минутами
  • HTTPS обязательно: Все соединения защищены SSL/TLS
  • Origin проверка: Защита от CSRF атак

  • SQLite/PostgreSQL
  • 512MB RAM
  • 1GB дискового пространства

Клиентская часть:

  • PyQt6
  • OpenCV (для QR-сканирования)
  • 100MB дискового пространства

Tracker33 представляет собой современную, масштабируемую систему мониторинга рабочего времени с инновационной QR-аутентификацией. Система демонстрирует применение передовых технологий веб-разработки, desktop приложений и современных принципов безопасности.

Ключевые достижения:
  • Полнофункциональная система мониторинга с современным UI/UX
  • Инновационная QR-аутентификация для публичного распространения
  • Безопасная архитектура с защитой от современных угроз
  • Высокая производительность и масштабируемость
  • Готовность к промышленному использованию
Техническая экспертиза:

  • PyQt6 для кроссплатформенного desktop клиента
  • QR-коды + OpenCV для инновационной аутентификации
  • Многопоточность и асинхронное программирование
  • Современные практики безопасности и разработки

Система готова к промышленному использованию и дальнейшему развитию в направлении современных методов аутентификации, расширенной аналитики и интеграции с корпоративными системами.
