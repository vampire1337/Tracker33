# 🚂 Простое развертывание Tracker33 на Railway

> **Для демонстрации портфолио - минимальные ресурсы, SQLite база данных**

## 🚀 Быстрое развертывание

### 1. Установка Railway CLI

```bash
npm install -g @railway/cli
```

### 2. Автоматический скрипт

```bash
# Linux/Mac
./scripts/railway-deploy.sh

# Windows  
scripts\railway-deploy.bat
```

**Готово!** Скрипт автоматически:
- Создаст проект на Railway
- Настроит переменные окружения
- Развернет с SQLite базой данных (без дополнительных ресурсов)
- Применит миграции и соберет статику

### 3. Ручное развертывание

```bash
# Авторизация
railway login

# Создание проекта
railway init

# Настройка переменных
railway variables set SECRET_KEY="$(python -c 'import secrets; print(secrets.token_urlsafe(50))')"
railway variables set DEBUG="False"
railway variables set ALLOWED_HOSTS="*.railway.app"

# Развертывание
railway up
```

## 💡 Особенности для портфолио

### ✅ Преимущества SQLite на Railway:

- **Бесплатно** - не тратит лимиты на базу данных
- **Быстрый старт** - нет времени на подключение к БД
- **Простота** - нет настройки внешних сервисов  
- **Достаточно** для демонстрации функционала

### ⚡ Оптимизации ресурсов:

- **1 worker** Gunicorn вместо нескольких
- **Локальный кэш** вместо Redis
- **Минимальное логирование** в продакшене
- **Отключены** неиспользуемые middleware

### 📊 Потребление ресурсов:

```
RAM: ~50-80MB (вместо 200-300MB с PostgreSQL)
CPU: Минимальное
Диск: ~100MB (включая SQLite базу)
```
