# 🚀 Tracker33 Simple Client v2.1

Современный, легкий и надежный клиент для отслеживания активности с **интерактивной настройкой**.

## ✨ Особенности

- **Интерактивная настройка** - настройка при первом запуске
- **Минималистичный дизайн** - никаких тяжелых GUI  
- **Быстрый и стабильный** - всего ~450 строк кода
- **Безопасность** - пароли не видны при вводе
- **Кроссплатформенность** - Windows, Linux, macOS
- **Современная архитектура** - async/await, aiohttp

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements_simple.txt
```

### 2. Первый запуск
```bash
python simple_tracker.py
```

При первом запуске программа **автоматически** попросит вас ввести:
- Адрес сервера (по умолчанию http://127.0.0.1:8001)  
- Имя пользователя
- Пароль (скрытый ввод)

### 3. Готово!
После успешной настройки клиент сохранит настройки и начнет работу.

## ⚙️ Управление настройками

### Сброс настроек
```bash
python simple_tracker.py --reset
```

### Справка
```bash
python simple_tracker.py --help
```

### Изменение настроек
Просто запустите программу снова - она предложит изменить существующие настройки.

## 🔐 Безопасность

- **Скрытый ввод пароля** - пароль не отображается при вводе
- **Локальное хранение** - данные сохраняются только на вашем компьютере
- **Проверка подключения** - перед сохранением настроек проверяется авторизация

## 🎯 Что отслеживается

- ✅ Активные приложения и время их использования
- ✅ Количество нажатий клавиш (показатель активности)
- ✅ Автоматическое определение простоя
- ✅ Graceful shutdown при завершении

## 🛠️ Устранение проблем

### Не запускается
```bash
# Установите зависимости
pip install aiohttp psutil pynput pygetwindow

# Для Windows также установите
pip install pywin32 win10toast
```

### Ошибка подключения
1. Убедитесь что сервер запущен на указанном адресе
2. Проверьте правильность логина/пароля
3. Проверьте настройки файрвола

### Сбросить все настройки
```bash
python simple_tracker.py --reset
```

## 💡 Рекомендации

1. **Автозапуск**: Настройте автозапуск через Task Scheduler (Windows)
2. **Фоновый режим**: Используйте `nohup` на Linux
3. **Мониторинг**: Регулярно проверяйте логи на ошибки
4. **Безопасность**: Не передавайте файл config.json другим людям

## 🔧 Расширение функционала

Клиент легко расширяется:
