# Журнал изменений TimeTracker

## [1.0.0] - 2023-11-15

### Добавлено
- Полная кросс-платформенная поддержка Windows и Linux
- Модуль `path_utils.py` для работы с путями файлов на разных ОС
- Модуль `icon_utils.py` для работы с иконками на разных ОС
- Скрипт установки `install.sh` для Linux
- Скрипт установки `install.ps1` и `install.bat` для Windows
- Скрипт `cleanup.py` для очистки временных файлов и удаления приложения
- Обновлены README.md с инструкциями по установке для разных ОС

### Исправлено
- Проблема с ротацией лог-файлов (PermissionError: WinError 32)
- Жестко закодированные пути в коде заменены на кросс-платформенные
- Улучшена обработка исключений при работе с файловой системой
- Исправлено поведение приложения при запуске в автоматическом режиме
- Корректное определение директорий для хранения данных в зависимости от ОС

### Изменено
- Реализация логирования для предотвращения блокировки файлов
- Метод загрузки конфигурации для поиска файла в различных местах
- Метод сохранения конфигурации для корректной работы на разных ОС
- Улучшена инициализация приложения при первом запуске
- Обновлены зависимости в requirements.txt с указанием точных версий

### Безопасность
- Добавлена проверка прав для скриптов установки
- Улучшена обработка пользовательских учетных данных
- Безопасное хранение токена авторизации

## [0.9.0] - 2023-10-01

### Добавлено
- Первоначальная версия приложения TimeTracker
- Отслеживание активности приложений
- Мониторинг клавиатуры и мыши
- Базовая настройка через конфигурационный файл
- Отправка данных на сервер
- Возможность работы в автономном режиме
- Системный трей и главное окно приложения
