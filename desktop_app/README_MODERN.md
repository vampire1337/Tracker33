## 🚀 Быстрый старт

### Windows (Самый простой способ)
1. **Скачайте архив** с клиентом
2. **Распакуйте** в любую папку
3. **Запустите** `start_modern.bat`
4. Готово! 🎉

### Ручная установка
```bash
# 1. Установите зависимости
pip install -r requirements_modern.txt

# 2. Запустите клиент
python modern_client.py
```

## ⚙️ Первая настройка

При первом запуске:

1. **Автоматически откроется окно настроек**
2. **Введите данные сервера:**
   - Адрес: `http://ваш-сервер:8001`
   - Логин: ваше имя пользователя
   - Пароль: ваш пароль

3. **Настройте параметры:**
   - Интервал проверки: 5 секунд
   - Порог простоя: 300 секунд

4. **Нажмите "Сохранить"**

5. **Клиент автоматически запустится!**

## 🐛 Устранение неполадок

### ❌ Не запускается
```bash
# Проверьте Python
python --version

# Переустановите зависимости
pip install --upgrade -r requirements_modern.txt

# Запустите вручную для диагностики
python modern_client.py
```

### 🔌 Проблемы подключения
1. **Проверьте адрес сервера** - должен быть доступен
2. **Проверьте логин/пароль** - используйте те же что для веб-интерфейса
3. **Проверьте файрвол** - разрешите исходящие соединения
4. **Проверьте сеть** - ping до сервера должен проходить

### 📦 Проблемы с треем
- **Windows 10/11**: убедитесь что уведомления включены
- **Linux**: установите пакет трея для вашего DE
- **macOS**: дайте разрешения на уведомления

### ⌨️ Не отслеживается активность
```bash
# Windows: Запустите от имени администратора
# Linux: Добавьте пользователя в группу input
sudo usermod -a -G input $USER

# Перезагрузите компьютер после изменений
```
