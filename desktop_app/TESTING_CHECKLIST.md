## 🧪 **ПЛАН ТЕСТИРОВАНИЯ:**

### 1️⃣ **Запуск сервера**
```bash
cd Tracker33
python manage.py runserver 8001
```

### 2️⃣ **Тест API вручную**
```bash
python test_auth.py
# Должен вернуть: Status Code: 200, Token received: ...
```

### 3️⃣ **Запуск клиента**
```bash
cd desktop_app
python modern_client.py
# ИЛИ
dist/Tracker33_Client.exe
```

### 4️⃣ **Настройка клиента**
1. Кликнуть правой кнопкой на трей → "Настройки"
2. Нажать "🔍 Найти" → должен найти `http://127.0.0.1:8001`
3. Ввести логин: `heist`
4. Ввести пароль: `1234567vampire`
5. Нажать "🔍 Тест подключения" → должно быть "✅ Подключение успешно!"
6. Нажать "💾 Сохранить"

### 5️⃣ **Тест отслеживания**
1. В главном окне нажать "▶️ Запустить"
2. Должно появиться: "✅ Подключен"
3. Переключиться между приложениями
4. Проверить журнал событий на сообщения:
   - "🎯 Переключение на: ..."
   - "📊 Отправлена активность: ..."

### 6️⃣ **Проверка в веб-интерфейсе**
1. Открыть `http://127.0.0.1:8001/dashboard/`
2. Проверить что активность отображается
3. Проверить что приложения создаются автоматически
