# 🚀 Tracker33 Client - Быстрый старт

## 📋 **Пошаговая инструкция подключения**

### 1️⃣ **Запуск сервера**

#### На этом же компьютере (localhost):
```bash
cd Tracker33
python manage.py runserver 8001
```

#### На другом компьютере в сети:
```bash
cd Tracker33  
python manage.py runserver 0.0.0.0:8001
```

### 2️⃣ **Настройка клиента**

1. **Запустите клиент** (modern_client.py или EXE)
2. **Кликните правой кнопкой на иконку в трее** → "Настройки"
3. **Нажмите "🔍 Найти"** - клиент автоматически найдет сервер
4. **Введите логин и пароль** от веб-интерфейса
5. **Нажмите "🔍 Тест подключения"** для проверки
6. **Сохраните настройки**

### 3️⃣ **Адреса серверов**

#### Локальный сервер (на том же ПК):
```
http://127.0.0.1:8001
http://localhost:8001
```

#### Сервер в локальной сети:
```
http://192.168.1.100:8001  (замените IP на адрес вашего сервера)
http://10.0.0.50:8001      (или другой IP)
```

#### Удаленный сервер:
```
http://your-domain.com:8001
https://your-domain.com:8001  (если есть SSL)
```

## 🔧 **Устранение неполадок**

### ❌ **"Сервер недоступен"**
- Убедитесь что сервер запущен
- Проверьте правильность IP-адреса
- Убедитесь что порт 8001 не заблокирован

### ❌ **"API не найдено"**
- Убедитесь что сервер - это именно Tracker33
- Проверьте что URL содержит правильный протокол (http://)

### ❌ **"Неверный логин или пароль"**
- Используйте те же данные что и для веб-интерфейса
- Создайте пользователя через веб-интерфейс если его нет

### ❌ **"Тайм-аут подключения"**
- Проверьте интернет-соединение
- Увеличьте время ожидания
- Убедитесь что фаервол не блокирует подключение

## 🆘 **Нужна помощь?**

3. Посмотрите сообщения в статусе подключения
